# Für Community-Entwicklerinnen und -Entwickler

Dieses Projekt ist ausdrücklich zur unabhängigen Weiterentwicklung freigegeben. Du kannst es forken, verändern, dekompilieren und eigene Releases anbieten, soweit du die Lizenzbedingungen und Rechte Dritter beachtest.

Bitte dokumentiere deutlich, wenn du eine **inoffizielle Community-Version** veröffentlichst. Füge niemals Passwörter, laut.fm-Login-Tokens, Nextcloud-Zugangsdaten oder Signierschlüssel ins Repository ein. Die Lizenz für den eigenen Code ist MIT, die Rechte von Abhängigkeiten und laut.fm bleiben unberührt.

Die ursprüngliche Version 1.0.1 ist ein Experiment. Live-Senden, Login und Radioadmin-Funktionen sollten vor einer weiteren öffentlichen Freigabe auf einem echten Android-Gerät geprüft werden.
